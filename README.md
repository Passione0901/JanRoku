# 雀録 / Jang-roku

麻雀会用の戦績ツールです。対局の記録、メンバーごとの戦績、日別の収支をPC・スマートフォンから確認できます。

**[アプリを開く](https://passione0901.github.io/JanRoku/)**

## はじめに

戦績の閲覧には、麻雀会で共有する2つの合言葉が必要です。対局の登録・編集・削除やメンバーの追加には、GitHubへの接続と、このツールのリポジトリへの書き込み権限が必要です。権限がない場合は管理者に確認してください。

メンバーと対局記録は暗号化して共有し、各端末のブラウザー内で復号して表示します。公開されるデータから名前・戦績をそのまま読むことはできません。

## 合言葉で開く

アプリを開き、「合言葉1」「合言葉2」を入力し、「戦績を開く」を押します。合言葉は順番も区別します。日本語・全角文字も入力できます。入力した文字は伏せずに表示します。

入力した合言葉に対応するメンバー・履歴・初期ルールを自動で開きます。組を選ぶ操作はありません。別の組の記録を開くときは「ロック」を押して、別の合言葉を入力してください。ランキングや相性も、開いている記録だけで集計します。保存した鍵と前回入力した4人は組ごとに管理し、「ロック」は現在の記録の保存済み鍵を削除します。

各参加者は、自分の麻雀会の合言葉で開いてください。登録・編集には従来どおり各自のGitHub接続が必要です。

合言葉が一致しない場合は、入力した文字列に応じた別の名前・戦績・日付を表示します。同じ入力なら同じ表示になります。これは実際の記録とは無関係な閲覧専用のプレビューです。「合言葉を入力し直す」から入力し直せます。ブラウザーへの保存を選んだ場合、この表示も次回に引き継ぎます。

「このブラウザーに保存する」を選ぶと、復号用の鍵を端末に保存し、次回から入力を省略できます。合言葉の文字列そのものは保存しません。画面上部の「ロック」で保存した鍵を削除できます。共用端末では保存しないでください。

合言葉を知る人は全員同じ記録を閲覧できます。合言葉を第三者に渡さないでください。暗号化データは公開されるため、短い・推測しやすい合言葉は避けてください。ブラウザーに保存した鍵を取得された場合も、記録を読まれる可能性があります。

合言葉は閲覧用です。登録や編集には、別途GitHubの保存権限が必要です。

## 対局を記録する

「入力」タブで、入力方法を選びます。持ち点と収支の入力欄は切り替えて使用します。

### 持ち点入力

1. 対局日と対局形式（半荘・東風）を選びます。
2. メンバーを4人選び、それぞれの最終持ち点を入力します。
3. 「今回のルール」と、計算された順位・収支を確認します。
4. 「この半荘を登録」または「この東風を登録」を押します。

持ち点の末尾の「00」は自動で付きます。例えば **250と入力すると25,000点**です。マイナスの持ち点は、入力欄の「−」ボタンで切り替えられます。同点の場合は入力順を優先します。

「今回のルール」の「ルールを変更」から、開始時の持ち点・返し点・順位ウマ・オカ・箱下計算・箱割れの判定を変更できます。初期設定は25,000点持ち・30,000点返し、ウマは1位から順に+10／+5／−5／−10、オカあり、箱下計算あり、精算は5捨6入です。変更はその対局に適用されます。

麻雀会の初期ルールを変える場合は「設定」で変更を適用し、「ルールを保存」を押してください。その麻雀会の新規対局で使用され、ほかの麻雀会や過去の対局は変わりません。

### 収支入力

ウマ・オカなどを含めた、精算済みの収支が分かっている場合に使います。

1. 「収支入力」に切り替えます。
2. 対局日・対局形式・メンバー4人を選びます。
3. それぞれの収支をptで入力し、確認して登録します。

例えば **+35／+5／−15／−25** のように入力します。小数は0.1pt単位で入力できます。入力した収支をそのまま保存し、ウマ・オカや5捨6入の計算は重ねて行いません。

順位は収支の高い順、同じ収支の場合は入力順です。持ち点は「未記録」となり、最高・最低持ち点や箱割れ率の集計には含めません。

### 入力時の補足

- 入力方法を切り替えても、選択したメンバーと各モードの入力途中の値は残ります。
- 連続して対局を登録するときは、前回選んだメンバーが入力欄に残ります。
- 対局日は過去の日付も選べます。入力日時は保存時に自動で記録されます。
- 持ち点の合計が基準と異なる場合や、収支の合計が0でない場合は、保存前に確認画面が表示されます。入力間違いがないか確認してください。

## 戦績を見る

| 画面     | できること                                                                             |
| -------- | -------------------------------------------------------------------------------------- |
| 戦績     | 累計収支や平均順位などでランキングを並べ替え、メンバーごとの成績を比較できます。       |
| 個人戦績 | メンバー名を選ぶと、その人の集計・グラフ・対局履歴を確認できます。                     |
| 日別     | 開催日を選び、その日のメンバー別収支と対局を確認できます。                             |
| 履歴     | 対局を新しい順に確認し、メンバーで絞り込めます。各対局の編集・削除もここから行います。 |
| メンバー | メンバーを追加できます。対局履歴のあるメンバーは削除できません。                       |
| 設定     | 初期ルール、強さP・肩書きの説明、保存データの情報を確認できます。                      |

グラフはプルダウンからメンバー1人、または「全員」を選べます。**左が過去、右が最新**です。拡大・縮小ができ、線上の点を選ぶと日付や成績を確認できます。「直近10戦」は各対局の順位と収支を一覧表示します。右が最新です。

強さPは、メンバーの平均収支をもとにした偏差値です。強さPに応じて肩書きが変わります。対局数が少ない場合は数値が変動しやすいため、対局回数も合わせて確認してください。

画面上部の切り替えボタンで、ダークモード・ライトモードを選べます。

## 端末間の同期

### 初回の接続

1. アプリの「同期設定」を開きます。
2. 画面の案内に沿って、自分のGitHubアカウントで専用トークンを用意します。対象リポジトリは **JanRoku**、必要な権限は **Contents: Read and write** です。
3. 「GitHubトークン」欄に貼り付け、「接続する」を押します。
4. 「接続済み・保存できます」と表示されたら、登録や編集ができます。

トークンは接続したブラウザーに保存されるため、通常は再読み込みやブラウザーを閉じるたびに入力し直す必要はありません。別の端末・ブラウザーでは、それぞれ接続してください。期限切れやサイトデータの削除後は再接続が必要です。

トークンを他の人に渡さないでください。共用端末では、利用後に「接続を解除」を押してください。トークンの権限と保存方法の詳細は、同期設定内の「トークンの権限と保存について」で確認できます。

### 更新が見えないとき

「同期設定」の「最新データを読み込む」を押してください。通常は自動でも更新されます。

保存に失敗した場合は、接続状態とエラーメッセージを確認してください。通信が途切れた場合は、再登録する前に履歴を確認すると二重登録を防げます。

以前ブラウザー内だけに保存していた記録は、「同期設定」の「この端末のデータを取り込む」から内容を確認して追加できます。

個人戦績の「対戦相手との相性」は、相手より順位が上だった回数÷同卓回数で判定します。同卓5戦以上で70%以上を「良い」、30%以下を「悪い」とし、それ以外では同卓3戦以上で55%以上を「やや良い」、45%以下を「やや悪い」と表示します。普通と対局数不足の相手は表示しません。

個人戦績の「日別の最高・最低収支」は、選択した日に行った各対局の収支を比較します。1対局のみの日は最高収支だけを表示します。
